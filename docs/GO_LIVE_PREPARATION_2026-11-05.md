- Independent automatic heartbeat freshness is five minutes throughout the year. Manual jobs cannot refresh it. Delayed checkout reconciliation is included in business attention counts. `GET /api/jobs?health=true&strict=true` returns HTTP 503 for either stale scheduling or business attention.
- Added a distinct production-only `MONITORING_HEALTH_SECRET`. It permits health reads only; it cannot run maintenance. The write-capable scheduler secret is not needed by the external monitor.
- Raised the bounded database connection allowance from one to three seconds, preserving the 24-second storage and 18-second provider budgets. Production logs showed a cold database connection timeout under the old allowance, followed by a successful retry.
- Added safe receipt logs after Stripe signature validation and durable handling: event ID/type, mode and whether it was a configuration probe. No customer payload, card data, QR token, signing secret or checkout client secret is logged.
- Preserved the modern public UI, artwork, accepted steak package, prices, scoring and staff permissions. Sales, automatic Payment Link imports, refund writes, Eventbrite sync and production test fixtures remain disabled.
